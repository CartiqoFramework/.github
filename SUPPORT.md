# Getting help

Pick whichever fits, and please only pick one so a question does not get answered twice.

| I want to | Go here |
| :-- | :-- |
| Ask a question, or get help using something | [Our Discord](https://discord.gg/YTKp4MnN9Q) |
| Report a bug in a public repository | The repository's [issues](https://github.com/CartiqoFramework) tab |
| Suggest a feature | Issues, using the feature request template |
| Report a security problem | Read [SECURITY.md](SECURITY.md) first, do not open an issue |
| Report someone impersonating CARTIQO | [Impersonation report](https://github.com/CartiqoFramework/.github/issues/new?template=impersonation-report.yml) |
| Hire us to build something | [cartiqo.xyz/commission](https://cartiqo.xyz/commission) |
| Anything else | [hello@cartiqo.xyz](mailto:hello@cartiqo.xyz) |

## Before you ask

Search the existing issues first. If someone has already reported it, add what you know to that thread instead of opening a second one.

When you do ask, the three things that get a question answered fastest are what you expected, what actually happened, and enough detail for someone else to reproduce it. Versions, the exact command, and the full error text beat a screenshot of a screenshot.

## What we can and cannot promise

We are a small independent studio. Issues on public repositories and questions in Discord get answered when we get to them, usually within a few days. Paid client work and security reports jump the queue. Nothing here is a support contract, and if you need one, [talk to us](mailto:hello@cartiqo.xyz).
